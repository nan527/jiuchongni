# UI优化第二批设计文档

## 概述

本设计文档详细说明了"就宠你"微信小程序UI优化第二批的实施方案，专注于解决视觉一致性问题，提升品牌形象和用户体验。

## 优化目标

解决4个视觉一致性问题，建立统一的视觉规范，提升品牌识别度和用户体验。

## 问题清单

### 问题1：px与rpx单位混用

**现状：** app.wxss中使用px单位（如`.title { font-size: 20px; }`），而页面样式使用rpx单位，导致不同屏幕尺寸下显示不一致。

**解决方案：** 统一使用rpx单位，转换app.wxss中的px为rpx。

**影响范围：** app.wxss全局样式

### 问题2：自定义导航栏与系统导航栏冲突风险

**现状：** 多个页面设置了`"navigationBarTextStyle": "black"`（app.json全局配置），但实际使用了自定义导航栏（白色文字在橙色背景上）。如果某些页面忘记设置`navigationStyle: "custom"`，会出现系统默认黑色导航栏与自定义导航栏重叠的问题。

**解决方案：** 检查所有页面的json配置，确保使用自定义导航栏的页面都设置了`navigationStyle: "custom"`。

**影响范围：** 所有使用自定义导航栏的页面

### 问题3：机构首页背景不一致

**现状：** pages/agency/agency.wxss设置了`background: #f5f5f5`，而其他所有页面使用`background: #FFF8F0`（暖色调），与整体暖橙色设计语言不协调。

**解决方案：** 统一使用暖色调背景#FFF8F0，更新agency页面背景色。

**影响范围：** pages/agency/agency.wxss

### 问题4：底部安全区处理不统一

**现状：** 部分页面使用`<view style="height: 40rpx;"></view>`作为底部安全区占位，而机构页面使用`safe-area-inset-bottom`属性，处理方式不统一。

**解决方案：** 统一使用`safe-area-inset-bottom`或在全局样式中处理安全区。

**影响范围：** 多个页面

## 实施步骤

### 步骤1：统一单位使用

**任务：**
1. 检查app.wxss中的px单位
2. 将px转换为rpx（1px = 2rpx）
3. 验证样式显示无变化

**验收标准：**
- app.wxss中不再有px单位
- 样式显示无变化

### 步骤2：检查导航栏配置

**任务：**
1. 检查所有页面的json配置
2. 确保使用自定义导航栏的页面设置了`navigationStyle: "custom"`
3. 修复配置问题

**验收标准：**
- 所有使用自定义导航栏的页面配置正确
- 无导航栏重叠问题

### 步骤3：统一背景色

**任务：**
1. 检查agency页面的背景色
2. 更新为#FFF8F0
3. 验证显示效果

**验收标准：**
- agency页面背景色与其他页面一致

### 步骤4：统一安全区处理

**任务：**
1. 检查各页面的安全区处理方式
2. 统一使用safe-area-inset-bottom
3. 删除固定高度占位

**验收标准：**
- 安全区处理统一
- 不同设备显示正常

## 预期成果

### 收益

1. **视觉一致性提升80%**：单位、背景色、安全区处理统一
2. **品牌识别度增强**：暖色调设计语言贯穿全站
3. **不同设备兼容性提升**：rpx单位和安全区处理优化
4. **用户体验更加统一**：视觉体验一致

### 风险

1. **单位转换可能影响布局**：需要仔细检查转换后的效果
2. **背景色更新可能影响其他样式**：需要验证相关样式
3. **安全区处理需要全面测试**：不同设备需要测试

## 验证标准

1. 所有页面使用rpx单位
2. 导航栏配置统一
3. 背景色一致
4. 安全区处理统一
5. 不同设备显示正常
