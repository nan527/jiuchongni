# 首页（index）视觉重设计文档

## 1. 设计目标

在保持品牌主色调 `#FF9800`（暖橙色）不变的前提下，将首页升级为**新拟态（Neumorphism）+ 活力渐变**的混合风格，提升整体质感与现代感，同时引入丰富的微动效与转场动画。

## 2. 视觉风格定义

### 2.1 风格基底：新拟态（Neumorphism）

- **核心特征**：柔和的凸起与凹陷阴影，模拟真实物理光照
- **阴影公式**：
  - 凸起（外凸）：`box-shadow: 6rpx 6rpx 16rpx rgba(174, 144, 116, 0.15), -6rpx -6rpx 16rpx rgba(255, 255, 255, 0.9);`
  - 凹陷（内凹）：`box-shadow: inset 4rpx 4rpx 8rpx rgba(174, 144, 116, 0.1), inset -4rpx -4rpx 8rpx rgba(255, 255, 255, 0.8);`
- **圆角**：统一使用大圆角（`24rpx` ~ `40rpx`），强化柔软亲和感

### 2.2 渐变融入点

| 元素 | 渐变方案 |
|------|----------|
| 头部背景 | `linear-gradient(135deg, #FF9800, #FFB74D, #FF8A65)` 多层渐变 |
| 功能入口图标背景 | `linear-gradient(135deg, #FFF3E0, #FFE0B2)` 浅橙渐变 |
| 卡片背景 | `linear-gradient(180deg, #FFFAF5, #FFF3E0)` 微弱暖色渐变 |
| 按钮/标签 | 主按钮使用 `#FF9800 → #FFB74D` 渐变 |

### 2.3 颜色体系

```
背景色：#FFF8F0（页面底色）
卡片底色：#FFFAF5 → #FFF3E0（渐变）
主色：#FF9800
辅助色：#FFB74D
文字主色：#3D2C1E
文字辅助色：#8C7A6B
价格色：#E65100
阴影暗色：rgba(174, 144, 116, 0.15)
阴影亮色：rgba(255, 255, 255, 0.9)
```

## 3. 页面结构重设计

### 3.1 头部区域（Hero Header）

- **背景**：大圆弧底部（`border-radius: 0 0 50rpx 50rpx`）+ 多层橙色渐变
- **装饰**：添加 2~3 个半透明白色圆形（`border-radius: 50%`）作为几何装饰，增强活力感
- **标题**："就宠你" 使用加粗白色大字（`44rpx`，`font-weight: 800`）
- **副标题**："让每一只毛孩都被温柔以待" 白色半透明（`rgba(255,255,255,0.9)`）
- **搜索框**：
  - 外凸阴影样式
  - 白色背景 + 圆角 `40rpx`
  - 内凹输入区域（可选）
  - 右侧搜索按钮使用渐变背景

### 3.2 功能入口（Func Entry）

- **布局**：水平三等分，图标 + 文字
- **容器**：白色卡片，大圆角 `24rpx`，外凸阴影，向上覆盖头部底部（`margin-top: -40rpx`）
- **图标**：
  - 尺寸：`60rpx x 60rpx`
  - 圆角：`18rpx`（微圆角方形）
  - 背景：`linear-gradient(135deg, #FFF3E0, #FFE0B2)`
  - 阴影：`0 4rpx 12rpx rgba(255, 152, 0, 0.15)`
  - 图标颜色保持各功能主题色（橙、紫、蓝）

### 3.3 推荐机构（Agency Section）

- **板块标题**：左侧粗体标题 + 右侧"查看更多"箭头
- **卡片布局**：由当前两列网格改为**横向滚动卡片**（`scroll-x`）
  - 卡片宽度：`280rpx`
  - 卡片高度：自适应
  - 间距：`20rpx`
  - 最后一张卡片右侧留 `32rpx` 安全边距
- **卡片样式**：
  - 白色背景 + 微弱渐变
  - 大圆角 `24rpx`
  - 外凸阴影
  - 图片区域：`280rpx x 160rpx`，圆角与卡片一致（`border-radius: 24rpx 24rpx 0 0`）
  - 内容区域：`padding: 16rpx 20rpx 20rpx`
  - 标签：圆角标签，浅橙背景
  - 机构名：单行省略
  - 地址：小字辅助色，带定位图标

### 3.4 机构服务（Service Section）

- **卡片布局**：横向滚动卡片，与推荐机构一致
- **卡片样式**：
  - 图片区域 + 标签 + 服务名 + 机构名 + 价格
  - 价格使用 `#E65100` 加粗

## 4. 动效方案

### 4.1 卡片入场动画（Fade In Up）

页面加载时，各区块按顺序渐入：

```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(40rpx); }
  to   { opacity: 1; transform: translateY(0); }
}
```

- 头部：立即显示
- 功能入口：延迟 `100ms`
- 推荐机构标题：延迟 `200ms`
- 推荐机构卡片：延迟 `300ms`，每张卡片额外错开 `80ms`
- 服务区块：延迟 `400ms`

**微信小程序实现**：使用 `animation` API 或 `transition` 配合 `setTimeout`/`setInterval`。

### 4.2 按钮/卡片点击反馈

- **缩放**：`transform: scale(0.96)`，时长 `120ms`，缓动 `ease-out`
- **阴影变化**：点击时阴影缩小，模拟按压感
- **功能入口图标**：点击时图标内部有轻微缩放 + 阴影收缩

### 4.3 横向滚动动效

- 滚动时卡片有轻微倾斜（`skew`）或缩放变化（可选，复杂度较高，可延后）
- 基础版：平滑滚动 + 滚动条隐藏

### 4.4 页面转场动画

- **进入**：页面从右侧滑入（`translateX(100%) → translateX(0)`），时长 `250ms`
- **返回**：页面向左滑出（`translateX(0) → translateX(-30%)`），配合下层页面右移
- **实现方式**：利用微信小程序 `page-meta` + `page-container`（基础库 2.29.0+）或自定义 `navigator` 样式

> 注：由于微信小程序对页面级转场动画支持有限，优先在页面内部使用滚动动效和入场动画。页面转场可作为增强项，使用 `page-container` 实现。

### 4.5 搜索框交互

- **聚焦**：搜索框阴影加深，宽度微扩（`scale(1.02)`），时长 `200ms`
- **建议列表**：从搜索框底部向下滑入（`translateY(-20rpx) → translateY(0)` + `opacity: 0 → 1`）

## 5. 组件详细规格

### 5.1 新拟态阴影变量

```less
// 外凸阴影（卡片、按钮、图标）
@shadow-raised: 6rpx 6rpx 16rpx rgba(174, 144, 116, 0.15),
                -6rpx -6rpx 16rpx rgba(255, 255, 255, 0.9);

// 内凹阴影（输入框、开关）
@shadow-inset: inset 4rpx 4rpx 8rpx rgba(174, 144, 116, 0.1),
               inset -4rpx -4rpx 8rpx rgba(255, 255, 255, 0.8);

// 按压态阴影
@shadow-pressed: 3rpx 3rpx 8rpx rgba(174, 144, 116, 0.12),
                 -3rpx -3rpx 8rpx rgba(255, 255, 255, 0.95);
```

## 6. 实现要点与约束

1. **性能**：新拟态依赖多层阴影，需避免过多重绘。横向滚动卡片使用 `scroll-view` 并开启 `scroll-x`，注意图片懒加载。
2. **兼容性**：`page-container` 转场动画需要基础库 2.29.0+，若不支持则优雅降级为无转场。
3. **图片处理**：继续使用 `utils/fileHelper.js` 的 `resolveTempUrls` 解析云存储图片。
4. **响应式**：卡片宽度使用固定值 + `scroll-x`，适配不同屏幕宽度。
5. **无障碍**：确保所有可点击元素有清晰的点击态反馈，文字与背景对比度符合 WCAG 标准。
