# 首页 UI 重设计 — 温暖治愈风

> 日期：2026-05-26
> 范围：`pages/index/` 首页（宠物主人视角）
> 风格：温暖治愈风

---

## 1. 设计目标

将首页从标准 Vant 模板风格升级为温暖治愈风格，提升品牌辨识度和用户情感连接。只改视觉层，不改数据逻辑。

## 2. 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FFF8F0` | 暖奶油色，替代 `#f5f5f5` |
| 主色 | `#FF9800` | 保持不变 |
| 渐变 | `#FF9800 → #FFB74D` | 135deg，用于头部 |
| 辅助色 | `#FFF3E0` | 浅橙，用于标签/图标背景 |
| 卡片底色 | `#FFFAF5` | 暖白 |
| 文字主色 | `#3D2C1E` | 暖棕，替代 `#333` |
| 文字副色 | `#8C7A6B` | 暖灰，替代 `#999` |
| 分隔线 | `#F0E6D8` | 暖米色 |
| 阴影 | `rgba(61,44,30,0.06)` | 暖色阴影 |

## 3. 页面结构

```
┌─────────────────────────────────┐
│  渐变头部（~280rpx）              │
│    搜索栏（白色半透明底）          │
├─────────────────────────────────┤
│  功能入口（三列圆形图标）          │
│    浏览机构 | AI创作 | 健康管理    │
├─────────────────────────────────┤
│  推荐服务标题栏 + 查看更多         │
│  卡片网格（两列）                  │
└─────────────────────────────────┘
```

## 4. 组件设计

### 4.1 渐变头部
- 背景：`linear-gradient(135deg, #FF9800, #FFB74D)`
- 高度：约 280rpx
- 底部圆角过渡：`border-radius: 0 0 40rpx 40rpx`
- 搜索栏：白色半透明底 `rgba(255,255,255,0.9)`，圆角 40rpx
- 导航栏：设 `navigationBarBackgroundColor` 为渐变起始色

### 4.2 功能入口
- 三个圆形按钮横向均匀分布
- 尺寸：`100rpx × 100rpx`，`border-radius: 50%`
- 背景：`#FFF3E0`，图标色 `#FF9800`
- 底部文字：`24rpx`，色 `#3D2C1E`
- 点击态：`transform: scale(0.95)`
- 入口：浏览机构（核心）、AI创作（预留）、健康管理（预留）

### 4.3 推荐服务卡片
- 底色 `#FFFAF5`，圆角 `24rpx`
- 图片高度 `200rpx`，顶部圆角
- 标签：`van-tag`，`#FFF3E0` 底 + `#FF9800` 文字
- 店名：`28rpx`，`font-weight: 600`，色 `#3D2C1E`
- 价格：`26rpx`，色 `#FF9800`，`font-weight: 700`
- 位置：`22rpx`，色 `#8C7A6B`
- 阴影：`0 4rpx 16rpx rgba(61,44,30,0.06)`
- 两列等宽，间距 `20rpx`

### 4.4 标题栏
- 左侧标题：`34rpx`，`font-weight: 700`，色 `#3D2C1E`
- 右侧"查看更多"：`24rpx`，色 `#8C7A6B`，带 `>` 箭头

## 5. 间距规范

- 全局水平 padding：`32rpx`
- 区块间距：`32rpx`
- 卡片间距：`20rpx`
- 底部安全区：`40rpx`

## 6. 页面跳转

| 入口/链接 | 目标 | 说明 |
|-----------|------|------|
| 浏览机构 | 机构列表页（待新建或复用） | 带筛选功能 |
| AI 创作 | toast "即将上线" | 预留 |
| 健康管理 | toast "即将上线" | 预留 |
| 推荐服务卡片 | `service-detail?id=xxx` | 不变 |
| 查看更多 | 机构浏览页 | 同"浏览机构" |

## 7. 改动文件

| 文件 | 改动 |
|------|------|
| `pages/index/index.wxml` | 重写模板：渐变头部、自定义功能入口、推荐卡片 |
| `pages/index/index.less` | 重写样式：暖色调、渐变、卡片样式 |
| `pages/index/index.js` | 小改：添加入口跳转逻辑（浏览机构页面跳转） |
| `pages/index/index.json` | 可能移除不需要的 Vant 组件注册 |
| `app.wxss` | 更新全局 CSS 变量为暖色调 |

## 8. 不变的部分

- `index.js` 的 `loadFosters()` 和 `loadServices()` 数据逻辑不变
- 云数据库查询不变
- 卡片点击跳转逻辑不变
- 下拉刷新逻辑不变
