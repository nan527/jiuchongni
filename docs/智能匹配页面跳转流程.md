## 二、跳转详细逻辑

### 1. 首页 → 智能匹配

- **触发方式**：点击首页功能入口"智能匹配"按钮
- **跳转代码**：
```javascript
// pages/index/index.js
toSmartMatch() {
  wx.navigateTo({ url: '/pages/smart-match/smart-match' });
}
```
- **跳转方式**：`wx.navigateTo`（保留在页面栈中，可返回）
- **传参**：无参数

---

### 2. 智能匹配页 → 服务详情页

- **触发方式**：匹配结果列表中，点击"立即预约"按钮
- **跳转代码**：
```javascript
onBookTap(e) {
  const serviceId = e.currentTarget.dataset.serviceid;
  if (serviceId) {
    wx.navigateTo({ url: `/pages/service-detail/service-detail?id=${serviceId}` });
  }
}
```
- **跳转方式**：`wx.navigateTo`
- **传参**：`id` — 服务记录 `_id`（来自 `agency_services` 集合）

---

### 3. 智能匹配页 → 机构详情页

- **触发方式**：匹配结果列表中，点击"查看详情"按钮
- **跳转代码**：
```javascript
onDetailTap(e) {
  const agencyId = e.currentTarget.dataset.agencyid;
  if (agencyId) {
    wx.navigateTo({ url: `/pages/agency-detail/agency-detail?id=${agencyId}` });
  }
}
```
- **跳转方式**：`wx.navigateTo`
- **传参**：`id` — 机构档案 `_id`（来自 `agency_profiles` 集合）

## 三、智能匹配核心流程（onMatchTap）

**入口函数**：`onMatchTap()`（pages/smart-match/smart-match.js）

### 完整流程

```
用户点击"开始智能匹配"
       │
       ▼
  ① 校验：是否已选宠物？
       │ 未选 → showToast("请先选择宠物") → return
       ▼
  ② 调用 AI 云函数解析需求
       │ wx.cloud.callFunction({ name: 'ai_handler', action: 'smart_match_parse' })
       │ 输入：userText（用户文本）+ petInfo（宠物信息）
       │ 输出：parsed（解析结果对象）
       │ 失败时降级到 fallbackSmartMatch（正则提取）
       ▼
  ③ 查询已审核机构 + 所有服务
       │ Promise.all([
       │   agency_profiles.where({ auditStatus: 'approved' }).limit(100),
       │   agency_services.orderBy('createTime', 'desc').limit(100)
       │ ])
       ▼
  ④ 构建 (agency, service) 配对
       │ services.map → 关联 agency，过滤无机构的
       ▼
  ⑤ 硬性筛选（不满足直接排除）
       │ - serviceCategory：按服务分类过滤
       │ - location：按地域过滤（_isLocationMatch，支持省份/城市互查）
       │ - budget.max：按预算上限过滤
       ▼
  ⑥ 软性评分 + 排序（满分 100，比例放大）
       │ _calcScore() 计算匹配分 → 降序排列 → 取前 10 条
       ▼
  ⑦ 生成匹配理由
       │ _generateReason() 使用同义词扩展匹配生成理由文本
       ▼
  ⑧ setData → 渲染结果列表
       │ resultList, parsedIntent, hasResult, resultCount
       ▼
  用户可点击"查看详情"或"立即预约"跳转
```

## 四、关键变量与数据结构

### 页面 Data

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `petList` | Array | 当前用户的宠物列表 |
| `selectedPetId` | String | 当前选中的宠物 `_id` |
| `selectedPet` | Object | 当前选中的宠物完整对象 |
| `userText` | String | 用户输入的需求文本 |
| `resultList` | Array | 匹配结果列表，每项含 `{ service, agency, matchScore, matchPercent }` |
| `parsedIntent` | Object | AI 解析结果，含 `keywords, preferences, serviceCategory, location, budget, urgency` |
| `loading` | Boolean | 匹配中状态 |
| `hasResult` | Boolean | 是否已完成匹配 |
| `resultCount` | Number | 匹配结果数量 |

### AI 解析结果结构（parsed）

```javascript
{
  keywords: ['寄养', '猫咪'],          // 关键词，用于匹配服务名/描述
  preferences: ['安静', '监控'],       // 偏好，用于匹配机构介绍
  serviceCategory: 'foster',           // 服务分类（foster/grooming/medical/door/null）
  location: '太原',                    // 用户指定城市（硬性筛选）
  budget: { max: 100 },               // 预算上限（硬性筛选）
  keywords: ['监控'],                  // 关键词（软性评分）
  preferences: [],                     // 偏好标签（软性评分）
  urgency: 'urgent' | 'normal'        // 紧急程度
}
```

### 匹配结果单项结构（resultList 元素）

```javascript
{
  service: {
    _id: '...',
```

## 五、评分算法（_calcScore）

采用**比例放大机制**：只计算用户实际提到的维度，最终 `earned / maxEarned * 100`。

| 维度 | 满分 | 计分规则 | 何时计入 |
|------|------|---------|---------|
| 基础分 | 25 | 通过硬性筛选即得 | 始终 |
| 关键词匹配 | 40 | 每命中 1 个 +8，上限 40，支持同义词扩展 | 始终 |
| 偏好匹配 | 30 | 每命中 1 个 +10，上限 30，支持同义词扩展 | 用户提到偏好时 |
| 价格适配度 | 15 | 越接近预算中心分越高（+5/+10/+15） | 用户指定预算时 |
| 环境展示度 | 10 | 0张0分，1-2张5分，3+张10分 | 始终 |
| 紧急度加成 | 5 | 寄养服务且有空笼位时 +5 | 用户指定紧急时 |

## 六、涉及的数据库集合

| 集合名 | 用途 |
|--------|------|
| `pets` | 查询当前用户的宠物列表（`where({ ownerId: userId })`） |
| `agency_profiles` | 查询已审核机构（`where({ auditStatus: 'approved' })`） |
| `agency_services` | 查询所有服务，与机构配对 |
