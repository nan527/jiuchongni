# 智能匹配页面跳转流程文档

## 一、页面跳转总览

```
┌─────────────────┐     navigateTo      ┌──────────────────────┐     navigateTo      ┌────────────────────────────┐
│   首页 (index)   │ ──────────────────→ │  智能匹配 (smart-match) │ ──────────────────→ │  服务详情 (service-detail)  │
│  pages/index/    │                     │  pages/smart-match/    │                     │  pages/service-detail/      │
│                  │                     │                        │ ──────────────────→ │                            │
│                  │                     │                        │   navigateTo        │                            │
│                  │                     │                        │ ──────────────────→ │  机构详情 (agency-detail)    │
└─────────────────┘                     └────────────────────────┘                     └────────────────────────────┘
```

---

## 二、跳转详细逻辑

### 1. 首页 → 智能匹配

- **触发方式**：点击首页功能入口"智能匹配"按钮
- **跳转代码**：
```javascript
// pages/index/index.js
toSmartMatch() {
  wx.navigateTo({ url: '/pages/smart-match/smart-match' });
}
```
- **跳转方式**：`wx.navigateTo`（保留首页在页面栈中，可返回）
- **传参**：无参数

---

### 2. 智能匹配页 → 服务详情页

- **触发方式**：匹配结果列表中，点击某条结果卡片的"立即预约"按钮
- **跳转代码**：
```javascript
// pages/smart-match/smart-match.js
onBookTap(e) {
  const serviceId = e.currentTarget.dataset.serviceid;
  if (serviceId) {
    wx.navigateTo({ url: `/pages/service-detail/service-detail?id=${serviceId}` });
  }
}
```
- **跳转方式**：`wx.navigateTo`
- **传参**：`id` — 服务记录 `_id`（来自 `agency_services` 集合）
- **WXML 绑定**：
```xml
<view class="result-card__btn result-card__btn--book"
      bindtap="onBookTap"
      data-serviceid="{{item.service._id}}">
```

---

### 3. 智能匹配页 → 机构详情页

- **触发方式**：匹配结果列表中，点击某条结果卡片的"查看详情"按钮
- **跳转代码**：
```javascript
// pages/smart-match/smart-match.js
onDetailTap(e) {
  const agencyId = e.currentTarget.dataset.agencyid;
  if (agencyId) {
    wx.navigateTo({ url: `/pages/agency-detail/agency-detail?id=${agencyId}` });
  }
}
```
- **跳转方式**：`wx.navigateTo`
- **传参**：`id` — 机构档案 `_id`（来自 `agency_profiles` 集合）
- **WXML 绑定**：
```xml
<view class="result-card__btn result-card__btn--detail"
      bindtap="onDetailTap"
      data-agencyid="{{item.agency._id}}">
```

## 三、智能匹配核心流程（onMatchTap）

**入口函数**：`onMatchTap()`（pages/smart-match/smart-match.js 第 104-243 行）

### 完整流程

```
用户点击"开始智能匹配"
       │
       ▼
  ① 校验：是否已选宠物？
       │ 未选 → showToast("请先选择宠物") → return
       ▼
  ② 调用 AI 云函数解析需求
       │ wx.cloud.callFunction({ name: 'ai_handler', action: 'smart_match_parse' })
       │ 输入：userText（用户文本）+ petInfo（宠物信息）
       │ 输出：parsed（解析结果对象）
       ▼
  ③ 获取用户位置
       │ wx.getLocation({ type: 'gcj02' })
       │ 失败不阻断流程
       ▼
  ④ 查询已审核机构 + 所有服务
       │ Promise.all([
       │   agency_profiles.where({ auditStatus: 'approved' }),
       │   agency_services.orderBy('createTime', 'desc').limit(100)
       │ ])
       ▼
  ⑤ 构建 (agency, service) 配对
       │ services.map → 关联 agency，过滤无机构的
       ▼
  ⑥ 硬性过滤（不满足直接排除）
       │ - serviceCategory：按服务分类过滤
       │ - location：按地域过滤（_isLocationMatch）
       │ - budget.max：按预算上限过滤
       ▼
  ⑦ 软性评分 + 排序
       │ _calcScore() 计算匹配分 → 降序排列 → 取前 10 条
       ▼
  ⑧ 转换为百分比 + 生成匹配理由
       │ matchPercent = matchScore / 85 * 100
       │ _generateReason() 生成理由文本
       ▼
  ⑨ setData → 渲染结果列表
       │ resultList, aiReasons, parsedIntent, hasResult, resultCount
       ▼
  用户可点击"查看详情"或"立即预约"跳转
```

## 四、关键变量与数据结构

### 页面 Data

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `petList` | Array | 当前用户的宠物列表 |
| `selectedPetId` | String | 当前选中的宠物 `_id` |
| `selectedPet` | Object | 当前选中的宠物完整对象 |
| `userText` | String | 用户输入的需求文本 |
| `resultList` | Array | 匹配结果列表，每项含 `{ service, agency, matchScore, matchPercent }` |
| `aiReasons` | Object | `{ [serviceId]: '匹配理由文本' }` |
| `parsedIntent` | Object | AI 解析结果，含 `keywords, preferences, serviceCategory, location, budget, urgency` |
| `loading` | Boolean | 匹配中状态 |
| `hasResult` | Boolean | 是否已完成匹配 |
| `resultCount` | Number | 匹配结果数量 |

### AI 解析结果结构（parsed）

```javascript
{
  keywords: ['寄养', '猫咪'],          // 关键词，用于匹配服务名/描述
  preferences: ['安静', '监控'],       // 偏好，用于匹配机构介绍
  serviceCategory: 'foster',           // 服务分类（硬性筛选）
  location: '广东',                    // 地域（硬性筛选）
  budget: { max: 200 },               // 预算上限（硬性筛选）
  urgency: 'urgent' | null            // 是否紧急
}
```

### 匹配结果单项结构（resultList 元素）

```javascript
{
  service: {
    _id: '...',
    name: '精品猫咪寄养',
    category: 'foster',
    price: 100,
    priceUnit: '天',
    desc: '...',
    images: ['cloud://...'],
    coverImage: 'http://...',          // 临时 URL
    catTitle: '宠物寄养',
    agencyProfileId: '...',
  },
  agency: {
    _id: '...',
    orgName: '爱宠之家',
    region: '广东深圳',
    orgIntro: '...',
    serviceScope: '...',

    totalCages: 10,
  },
  matchScore: 72,                      // 原始评分
  matchPercent: 85,                    // 百分比（满分 85 → 100%）

```

## 五、评分算法（_calcScore）

**函数位置**：pages/smart-match/smart-match.js 第 246-278 行

| 维度 | 分值 | 逻辑 |
|------|------|------|
| 基础分 | 10 | 通过硬性筛选即得 |
| 关键词匹配 | +30（上限） | 每个关键词 +8，匹配池：服务名 + 描述 + 机构介绍 + 服务范围 + 机构名 |
| 偏好匹配 | +25（上限） | 每个偏好 +10，匹配池：机构介绍 + 服务范围 + 笼位描述 |
| 环境展示度 | +15 / +3 | 有环境图 +15，无环境图 +3 |
| 紧急度加成 | +5 | 紧急 + 寄养类 + 有空笼位 |
| **满分** | **85** | |
