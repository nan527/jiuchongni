### 3.8 健康管理 (`pages/health/health`)

**功能**：
- 宠物选择器（多个宠物时显示）
- 健康状态卡（体重、疫苗、驱虫）
- 体重趋势图（最近 7 次）
- 疫苗时间线（最近 5 条）
- 驱虫时间线（最近 5 条）
- 待办提醒（疫苗/驱虫到期）
- 快捷记录（体重、疫苗、驱虫、体检）
- 最近记录列表
- AI 健康风险预警（按钮触发，结果持久化）

**数据**：
- `petList`：宠物列表
- `selectedPetId`：选中宠物 ID
- `latestWeight`：最新体重
- `weightTrend`：体重趋势
- `lastVaccine`：上次疫苗时间
- `lastDeworming`：上次驱虫时间
- `reminders`：待办提醒
- `recentRecords`：最近记录
- `weightChart`：体重图表数据
- `vaccineTimeline`：疫苗时间线
- `dewormingTimeline`：驱虫时间线
- `riskAlerts`：风险预警列表（level/title/desc）
- `riskSummary`：风险总结
- `riskLoading`：分析加载状态
- `riskError`：分析错误状态
- `riskDate`：上次分析时间

**交互**：
- 点击宠物 → 切换宠物
- 点击快捷记录 → 跳转添加记录
- 点击全部记录 → 跳转记录统计
- 点击"立即分析"/"重新分析" → 触发 AI 健康风险分析

### 3.10 智能匹配 (`pages/smart-match/smart-match`)

**功能**：
- AI 自然语言解析（用户输入描述性需求）
- 硬性筛选（服务类型、地区、预算）
- 软性评分（关键词、偏好、环境、紧急程度）
- 展示匹配结果（含匹配度百分比和匹配原因）

**数据**：
- `inputText`：用户输入的自然语言描述
- `parsedIntent`：AI 解析结果（serviceCategory、location、budget、keywords、preferences、urgency）
- `matchList`：匹配结果
- `isAnalyzing`：AI 解析加载状态

**匹配逻辑**：
- **硬性筛选**（不通过直接排除）：
  - 服务类型匹配（寄养/美容/医疗/上门/附加）
  - 地区匹配（省市映射，支持 31 省主要城市）
  - 预算匹配（服务价格 ≤ 预算上限）
- **软性评分**（满分 85 分）：
  - 关键词匹配（+30，每个命中 +8）
  - 偏好匹配（+25，每个命中 +10）
  - 环境图片（+15）
  - 紧急程度（+5）

**交互**：
- 输入自然语言描述 → 点击"智能匹配" → AI 解析 + 匹配
- 点击服务 → 跳转服务详情

## 八、页面跳转逻辑

### 8.1 认证流程

```
未登录 → 登录页
  ↓
选择角色
  ↓
宠物主人 → switchTab(首页)
机构 → redirectTo(机构首页)
管理员 → redirectTo(管理后台)
```

### 8.2 宠物主人流程

```
首页
  ↓
浏览机构 → 机构详情 → 服务详情 → 下单
  ↓
浏览服务 → 服务详情 → 下单
  ↓
智能匹配 → 服务详情 → 下单
  ↓
我的宠物 → 宠物详情 → 健康管理
```

### 8.3 机构流程

```
机构首页
  ↓
服务管理 → 添加/编辑服务
  ↓
订单管理 → 订单详情
  ↓
收入统计
  ↓
评价管理
```

### 8.4 管理员流程

```
管理后台
  ↓
审核列表 → 审核详情
  ↓
机构管理
  ↓
数据看板
```
