## 一、TabBar 页面（3 个）

### 1.1 首页服务广场 (`pages/index/index`)

**功能**：
- 展示推荐服务机构（卡片网格）
- 展示推荐服务项目（卡片网格）
- 功能入口：浏览机构、浏览服务、智能匹配
- 搜索功能

**数据**：
- `agencyList`：机构列表
- `serviceList`：服务列表
- `searchKeyword`：搜索关键词

**交互**：
- 点击机构卡片 → 跳转机构详情
- 点击服务卡片 → 跳转服务详情
- 点击功能入口 → 跳转对应页面

---

### 1.2 用户订单中心 (`pages/orders/orders`)

**功能**：
- 展示用户机构服务订单列表
- 订单状态筛选（全部/待付款/待接单/进行中/待确认/待评价/已完成/已取消）
- 订单详情查看
- 已完成订单显示"机构已回复"标识
- 付款倒计时（待付款订单）

**数据**：
- `allOrders`：全部订单
- `filteredOrders`：筛选后订单
- `activeStatus`：当前筛选状态
- `statusFilter`：状态筛选列表

**交互**：
- 点击订单 → 跳转订单详情/支付页
- 状态筛选 → 切换订单状态
- 确认完成 → 确认取回宠物/确认服务完成

### 3.10 智能匹配 (`pages/smart-match/smart-match`)

**功能**：
- 选择宠物（从宠物档案中选择）
- 输入自然语言需求描述（可选）
- AI 解析需求（调用云函数 `smart_match_parse`）
- 硬性筛选 + 软性评分
- 展示匹配结果（含匹配度百分比、匹配理由、四档颜色标识）
- 查看机构详情 / 立即预约

**数据**：
- `petList`：宠物列表
- `selectedPet`：选中宠物
- `userText`：用户输入文本
- `resultList`：匹配结果列表
- `aiReasons`：AI 匹配理由
- `loading`：加载状态

**匹配逻辑**：
- **硬性筛选**（不通过直接排除）：
  - 服务类型匹配（寄养/美容/医疗/上门）
  - 地区匹配（省市映射，支持 31 省主要城市）
  - 预算匹配（服务价格 ≤ 预算上限）
- **软性评分**（满分 100 分，按比例放大）：
  - 基础分 25（通过硬性筛选即得）
  - 关键词匹配（+8/命中，上限 40，支持同义词扩展）
  - 偏好匹配（+10/命中，上限 30，支持同义词扩展）
  - 价格适配度（+5/+10/+15，仅用户指定预算时计入）
  - 环境展示度（+5/+10，按环境图片数量）
  - 紧急度加成（+5，仅用户指定紧急时计入）
- **四档颜色**：
  - 80%+ 绿色（badge-high）
  - 50-80% 橙色（badge-med）
  - 20-50% 暖橙色（badge-low）
  - <20% 灰色（badge-very-low）

**交互**：
- 选择宠物 → 输入需求 → 点击"开始智能匹配"
- 点击"查看详情" → 跳转机构详情
- 点击"立即预约" → 跳转服务详情

## 八、页面跳转逻辑

### 8.1 认证流程

```
未登录 → 登录页
  ↓
选择角色
  ↓
宠物主人 → switchTab(首页)
机构 → redirectTo(机构首页)
管理员 → redirectTo(管理后台)
```

### 8.2 宠物主人流程

```
首页
  ↓
浏览机构 → 机构详情 → 服务详情 → 下单 → 支付 → 订单列表
  ↓
浏览服务 → 服务详情 → 下单 → 支付 → 订单列表
  ↓
智能匹配 → 机构详情/服务详情 → 下单
  ↓
我的宠物 → 宠物详情 → 健康管理 → AI 风险分析
```

### 8.3 机构流程

```
机构首页
  ↓
订单管理 → 接单/拒绝/开始服务/完成服务
  ↓
服务管理 → 添加/编辑服务
  ↓
宠物管理 → 笼位网格 → 移动宠物
  ↓
帖子接单 → 浏览帖子 → 接单
  ↓
收入统计 / 评价管理
```

### 8.4 管理员流程

```
管理后台
  ↓
审核列表 → 审核详情 → 通过/驳回
  ↓
机构管理 / 数据看板 / API 配置
```
