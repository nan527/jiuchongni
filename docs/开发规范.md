> 最后更新：2026-06-16

---

## 一、技术栈

### 1.1 核心技术

| 技术 | 版本 | 用途 |
|------|------|------|
| 微信小程序 | - | 前端框架 |
| Vant Weapp | ^1.11.7 | UI 组件库 |
| 微信云开发 | - | 后端服务 |

- 其他 UI 库（如 TDesign、WeUI）
- 外部 CDN 资源

## 二、目录结构规范

### 2.1 页面目录

```
pages/
  └── page-name/
      ├── page-name.js        # 页面逻辑
      ├── page-name.json      # 页面配置
      ├── page-name.wxml      # 页面模板
      ├── page-name.less      # 样式源文件（必须编辑此文件）
      └── page-name.wxss      # 样式编译产物（自动生成，禁止手动编辑）
```

### 2.2 文件命名

- **页面文件**：kebab-case（如 `health-add.js`）
- **组件文件**：kebab-case（如 `review-popup.js`）
- **工具函数**：camelCase（如 `fileHelper.js`）
- **常量文件**：camelCase（如 `constants/index.js`）

---

## 三、代码规范

### 3.1 JavaScript 规范

#### 变量命名：camelCase
```javascript
const petList = [];       // ✅
const selectedPetId = '';  // ✅
const pet_list = [];       // ❌
```

#### 私有方法：下划线前缀
```javascript
_buildReminders() {}  // ✅ 私有方法
_calcScore() {}       // ✅ 私有方法
```

#### 异步处理：统一 async/await
```javascript
async loadPets() {
  try {
    const res = await db.collection('pets').get();
    this.setData({ petList: res.data });
  } catch (e) {
    console.warn('[PageName] loadPets', e);
  }
}
```

#### 错误处理：withTimeout 包装
```javascript
const res = await withTimeout(
  db.collection('collection').get(),
  8000
);
```

### 3.2 WXML 规范

#### 事件传参：使用 data- 属性
```wxml
<view bindtap="onTap" data-id="{{item._id}}">
```

#### 阻止冒泡：卡片内按钮用 catchtap
```wxml
<view catchtap="onDelete" data-id="{{item._id}}">删除</view>
```

#### 列表渲染：使用唯一 key
```wxml
<view wx:for="{{list}}" wx:key="_id">
```

### 3.3 Less 规范

#### BEM 命名
```less
.record-card {
  &__header { display: flex; }
  &__title { font-size: 30rpx; }
  &--active { background: #FFF3E0; }
}
```

#### 最多嵌套 3 层

#### 使用 Less 变量，禁止硬编码颜色
```less
@primary: #FF9800;
@bg-page: #FFF8F0;
```

## 四、云开发规范

### 4.1 数据库查询
- 必须使用 `withTimeout()` 包装（8 秒超时）
- 使用 `limit()` 限制查询数量
- 使用 `field()` 选择需要的字段

### 4.2 云函数调用
- 机构端写操作必须通过云函数（绕过客户端安全规则）
- 云函数名称：`ai_handler`，通过 `action` 参数分发

### 4.3 文件上传
- 使用 `cloud://` 协议存储
- 显示时通过 `utils/fileHelper.js` 的 `resolveTempUrls()` 转为临时 URL

### 4.4 数据权限
- 客户端查询用 `where({ ownerId: userId })` 过滤
- 管理员/机构操作通过云函数绕过权限

---

## 五、样式规范

### 5.1 文件规则
- **必须编辑 `.less` 文件**
- `.wxss` 文件由编译器自动生成
- 编译命令：`npx lessc pages/xxx/xxx.less pages/xxx/xxx.wxss`

### 5.2 单位
- 使用 `rpx` 作为尺寸单位
- 避免使用 `px`、`%`、`vw`、`vh`

### 5.3 品牌色
- 主色：`#FF9800`（暖橙色）
- 禁止修改品牌色

## 七、性能规范

- 云查询使用 `withTimeout`（8 秒）
- 使用 `limit` 限制查询数量
- 图片使用 `resolveTempUrls` 批量解析
- `setData` 只更新变化的字段

---

## 八、安全规范

- 用户输入需验证
- 检查数据所有权
- 防止 XSS（不使用 `rich-text` 渲染用户输入）
- 机构端写操作通过云函数执行

---

## 九、禁止事项

1. 禁止编辑 `.wxss` 文件（必须编辑 `.less`）
2. 禁止使用 `eval()`
3. 禁止硬编码颜色值（使用 Less 变量）
4. 禁止使用外部 CDN
5. 禁止无超时控制的云调用
6. 禁止在模板中使用复杂表达式（如 `.indexOf()`）
7. 禁止使用 `index` 作为 `wx:key`
8. 禁止嵌套超过 3 层
9. 禁止直接调用 `wx.getSystemInfoSync()`（使用 `getStatusBarHeight()`）
10. Vant 组件不能直接 `flex:1`，需用 `view` 包裹
