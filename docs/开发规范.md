# 就宠你 - 开发规范

## 一、技术栈

### 1.1 核心技术

| 技术 | 版本 | 用途 |
|------|------|------|
| 微信小程序 | - | 前端框架 |
| Vant Weapp | ^1.11.7 | UI 组件库 |
| 微信云开发 | - | 后端服务 |
| Less | - | CSS 预处理器 |

### 1.2 禁止引入

- 其他 UI 库（如 TDesign、WeUI）
- 外部 CDN 资源
- npm 包（除 Vant Weapp）

---

## 二、目录结构规范

### 2.1 页面目录

```
pages/
  └── page-name/
      ├── page-name.js        # 页面逻辑
      ├── page-name.json      # 页面配置
      ├── page-name.wxml      # 页面模板
      ├── page-name.less      # 样式源文件（必须编辑）
      └── page-name.wxss      # 样式编译产物（自动编译）
```

### 2.2 文件命名

- **页面文件**：使用 kebab-case（如 `health-add.js`）
- **组件文件**：使用 kebab-case（如 `pet-card.js`）
- **工具函数**：使用 camelCase（如 `formatDate.js`）
- **常量文件**：使用 camelCase（如 `constants.js`）

## 三、代码规范

### 3.1 JavaScript 规范

#### 3.1.1 变量命名

```javascript
// ✅ 正确
const petList = [];
const selectedPetId = '';
let isLoading = false;

// ❌ 错误
const pet_list = [];  // 使用 camelCase
const PetList = [];   // 不使用 PascalCase
```

#### 3.1.2 函数命名

```javascript
// ✅ 正确
loadPetList() {}
onSelectPet() {}
_buildReminders() {}  // 私有方法用下划线前缀

// ❌ 错误
LoadPetList() {}  // 不使用 PascalCase
load_pet_list() {}  // 不使用 snake_case
```

#### 3.1.3 异步处理

```javascript
// ✅ 正确：使用 async/await
async loadPets() {
  try {
    const res = await db.collection('pets').get();
    this.setData({ petList: res.data });
  } catch (e) {
    console.warn('[PageName] loadPets', e);
  }
}

// ❌ 错误：使用 .then().catch()
loadPets() {
  db.collection('pets').get().then(res => {
    this.setData({ petList: res.data });
  }).catch(e => {
    console.warn(e);
  });
}
```

#### 3.1.4 错误处理

```javascript
// ✅ 正确：使用 withTimeout 包装
async loadData() {
  try {
    const res = await withTimeout(
      db.collection('collection').get(),
      8000
    );
    // 处理数据
  } catch (e) {
    console.warn('[PageName] loadData', e);
    // 显示错误提示
  }
}
```

### 3.2 WXML 规范

#### 3.2.1 条件渲染

```wxml
<!-- ✅ 正确 -->
<view wx:if="{{isLoading}}">
  <van-loading />
</view>

<view wx:elif="{{list.length > 0}}">
  <!-- 列表内容 -->
</view>

<view wx:else>
  <!-- 空状态 -->
</view>

<!-- ❌ 错误：避免在模板中使用复杂表达式 -->
<view wx:if="{{list.indexOf(item) > -1}}">  <!-- 不支持 -->
```

#### 3.2.2 列表渲染

```wxml
<!-- ✅ 正确 -->
<view wx:for="{{list}}" wx:key="_id">
  <text>{{item.name}}</text>
</view>

<!-- ❌ 错误：使用 index 作为 key -->
<view wx:for="{{list}}" wx:key="index">
```

#### 3.2.3 事件绑定

```wxml
<!-- ✅ 正确：使用 data- 传递参数 -->
<view bindtap="onTap" data-id="{{item._id}}" data-name="{{item.name}}">

<!-- ❌ 错误：使用 catch 冒泡 -->
<view catchtap="onTap">
```

### 3.3 Less 规范

#### 3.3.1 变量定义

```less
// ✅ 正确：使用变量.less 中的变量
.primary-color: @brand-orange;
.card-bg: @bg-card;

// ❌ 错误：硬编码颜色值
.card {
  background: #FFFAF5;  // 应使用变量
}
```

#### 3.3.2 嵌套规范

```less
// ✅ 正确：最多嵌套 3 层

  &__header {
    display: flex;
    align-items: center;
  }

  &__body {
    padding: 20rpx;
  }

    margin-top: 16rpx;
  }

// ❌ 错误：嵌套过深
.card {
  .header {
    .title {
      .icon {
        // 嵌套太深
      }
    }
  }
}
```

#### 3.3.3 BEM 命名

```less
// ✅ 正确：使用 BEM 命名
.record-card {
  &__header {
    display: flex;
  }

  &__title {
    font-size: 30rpx;
  }

  &--active {
    background: #FFF3E0;
  }
}

// ❌ 错误：使用语义化命名
.record-header {
  // 不符合 BEM
}
```

## 五、云开发规范

### 5.1 数据库查询

```javascript
// ✅ 正确：使用 withTimeout 包装
async loadData() {
  const res = await withTimeout(
    db.collection('collection')
      .where({ ownerId: userId })
      .orderBy('createTime', 'desc')
      .limit(50)
      .get(),
    8000
  );
  return res.data;
}

// ❌ 错误：无超时控制
async loadData() {
  const res = await db.collection('collection').get();
  return res.data;
}
```

### 5.2 数据权限

```javascript
// ✅ 正确：检查数据所有权
async loadData(petId) {
  const pet = this.data.petList.find(p => p._id === petId);
  if (!pet || pet.ownerId !== this._userId) {
    wx.showToast({ title: '无权访问', icon: 'none' });
    return;
  }
  // 加载数据
}
```

### 5.3 文件上传

```javascript
// ✅ 正确：使用 cloud:// 协议
async uploadImage(filePath) {
  const res = await wx.cloud.uploadFile({
    cloudPath: `uploads/${Date.now()}-${Math.random().toString(36).slice(2)}.jpg`,
    filePath,
  });
  return res.fileID;
}
```

## 六、样式规范

### 6.1 样式文件

- **必须编辑 `.less` 文件**
- `.wxss` 文件由编译器自动生成
- 如果编译失败，可手动创建 `.wxss` 文件同步样式

### 6.2 样式组织

```less
// pages/page-name/page-name.less

// 1. 页面容器
.page-name {
  min-height: 100vh;
  background: @bg-page;
}

// 2. 导航栏
.nav-bar {
  // ...
}

// 3. 内容区域
.content {
  // ...
}

// 4. 组件样式
.card {
  // ...
}

// 5. 状态样式
.loading {
  // ...
}

.empty {
  // ...
}
```

### 6.3 响应式单位

- 使用 `rpx` 作为尺寸单位
- 1rpx = 0.5px（在 750px 设计稿下）
- 避免使用 `px`、`%`、`vw`、`vh`

## 七、性能规范

### 7.1 数据加载

- 使用 `withTimeout` 控制超时（8秒）
- 使用 `limit` 限制查询数量
- 使用 `field()` 选择需要的字段

### 7.2 图片优化

- 使用云存储，不要使用 base64
- 使用 `resolveTempUrls` 批量解析临时 URL
- 使用 `mode="aspectFill"` 裁剪图片

### 7.3 内存优化

- 及时清理不需要的数据
- 避免在 `onShow` 中重复加载
- 使用 `setData` 时只更新变化的字段

## 八、安全规范

### 8.1 数据验证

```javascript
// ✅ 正确：验证用户输入
async addRecord(data) {
  if (!data.value || isNaN(data.value)) {
    wx.showToast({ title: '请输入有效数值', icon: 'none' });
    return;
  }
  // 保存数据
}
```

### 8.2 权限检查

```javascript
// ✅ 正确：检查用户权限
async deleteRecord(recordId) {
  const record = await db.collection('records').doc(recordId).get();
  if (record.ownerId !== this._userId) {
    wx.showToast({ title: '无权删除', icon: 'none' });
    return;
  }
  // 删除记录
}
```

### 8.3 防止 XSS

```javascript
// ✅ 正确：使用文本内容
<text>{{userInput}}</text>

// ❌ 错误：使用富文本
<rich-text nodes="{{userInput}}"></rich-text>
```

## 十一、禁止事项

1. **禁止编辑 .wxss 文件**：必须编辑 .less 文件
2. **禁止使用 eval()**：防止 XSS 攻击
3. **禁止硬编码颜色值**：使用变量.less 中的变量
4. **禁止使用外部 CDN**：所有资源本地化
5. **禁止无超时控制的云函数调用**：必须使用 withTimeout
6. **禁止在模板中使用复杂表达式**：使用 computed 或 data 处理
7. **禁止使用 index 作为 wx:key**：使用唯一标识符
8. **禁止嵌套超过 3 层**：保持代码简洁
