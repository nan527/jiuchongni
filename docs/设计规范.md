# 就宠你 - UI 设计规范

> 基于新拟态（Neumorphism）设计风格，以暖色调奶白为底，双阴影营造柔和立体感。

---

## 一、设计风格概述

**温暖新拟态（Warm Neumorphism）**：在奶白/米色背景上，通过一对暖色阴影（深色投影 + 浅色高光）塑造柔和的凹凸立体感。配合橙色渐变品牌色，营造温馨治愈的宠物服务氛围。

核心特征：
- 奶白底色 + 暖棕双阴影（非冷灰）
- 品牌橙三色渐变用于导航栏、按钮等高亮元素
- 圆润造型（大圆角 + 胶囊按钮）
- 按下缩放 + 阴影切换的触觉反馈
- 卡片入场 `fadeInUp` 动画（交错延迟）

## 三、阴影系统（核心）

新拟态的灵魂在于**双阴影**——暖棕投影 + 近白高光，配合奶白底色产生柔和的凹凸感。

### 3.1 三级阴影变量

```less
// 凸起态（默认卡片、按钮、筛选标签）
@shadow-raised:  6rpx 6rpx 16rpx rgba(174, 144, 116, 0.15),
                -6rpx -6rpx 16rpx rgba(255, 255, 255, 0.9);

// 按下态（:active 缩小偏移量）
@shadow-pressed: 3rpx 3rpx 8rpx rgba(174, 144, 116, 0.12),
                -3rpx -3rpx 8rpx rgba(255, 255, 255, 0.95);

// 内凹态（输入框、选中标签）
@shadow-inset:   inset 4rpx 4rpx 8rpx rgba(174, 144, 116, 0.1),
                 inset -4rpx -4rpx 8rpx rgba(255, 255, 255, 0.8);
```

### 3.2 功能性阴影

```less
// 品牌橙色光晕（选中按钮、活跃筛选项）
box-shadow: 0 4rpx 12rpx rgba(255, 152, 0, 0.25);

// 绿色光晕（通过按钮）
box-shadow: 0 4rpx 12rpx rgba(76, 175, 80, 0.25);

// 红色光晕（驳回按钮）
box-shadow: 0 4rpx 12rpx rgba(239, 83, 80, 0.25);
```

### 3.3 使用规则

| 场景 | 阴影 | 附加效果 |
|------|------|----------|
| 卡片默认 | `@shadow-raised` | — |
| 卡片按下 | `@shadow-pressed` | `scale(0.96~0.98)` |
| 输入框 | `@shadow-inset` | — |
| 输入框聚焦 | `@shadow-inset` + 加强 | `scale(1.02)` |
| 选中标签 | 品牌橙光晕 | 渐变背景 |
| 弹窗/下拉 | `0 16rpx 48rpx rgba(61,44,30,0.15)` | — |

## 四、渐变规范

### 4.1 导航栏渐变（三色）

```css
background: linear-gradient(135deg, #FF9800, #FFB74D, #FF8A65);
```

### 4.2 卡片渐变（上下暖色过渡）

```css
background: linear-gradient(180deg, #FFFAF5, #FFF6EE);
/* 或更深的橙底 */
background: linear-gradient(180deg, #FFFAF5, #FFF3E0);
```

### 4.3 按钮/标签渐变

```css
/* 品牌主按钮 */
background: linear-gradient(135deg, #FF9800, #FFB74D);

/* 通过（绿） */
background: linear-gradient(135deg, #4CAF50, #66BB6A);

/* 驳回（红） */
background: linear-gradient(135deg, #EF5350, #E57373);
```

### 4.4 图标背景渐变（四色系）

| 色系 | 渐变 | 适用 |
|------|------|------|
| 橙 | `#FFF3E0 → #FFE0B2` | 用户、宠物 |
| 蓝 | `#E3F2FD → #BBDEFB` | 设置、系统 |
| 绿 | `#E8F5E9 → #C8E6C9` | 数据、统计 |
| 紫 | `#F3E5F5 → #E1BEE7` | API 配置 |

## 五、动画系统

### 5.1 关键帧动画

```less
// 卡片入场（从下方滑入 + 淡入）
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(30rpx); }
  to   { opacity: 1; transform: translateY(0); }
}

// 简单淡入
@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

// 底部弹窗滑入
@keyframes slideUp {
  from { transform: translateY(100%); }
  to   { transform: translateY(0); }
}

// 装饰浮动圆
@keyframes float {
  0%, 100% { transform: translate(0, 0) scale(1); }
  50%      { transform: translate(-10rpx, 15rpx) scale(1.05); }
}

// 头像呼吸
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.08); }
}

// 数字入场
@keyframes countUp {
  from { opacity: 0; transform: translateY(20rpx); }
  to   { opacity: 1; transform: translateY(0); }
}

// 骨架屏闪烁
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
```

### 5.2 交互动画

| 交互 | 效果 | 时长 |
|------|------|------|
| 按下反馈 | `scale(0.92~0.96)` + 阴影切换 | 0.12~0.15s ease |
| 卡片入场 | `fadeInUp` + 交错延迟 | 0.4~0.5s，每张延迟 50~60ms |
| 统计数字 | `countUp` | 0.4s ease，延迟 0.3s |
| 底部弹窗 | `slideUp` / `translateY` | 0.3s ease |
| 装饰圆 | `float` 循环 | 5~7s ease-in-out infinite |
| 头像 | `pulse` 循环 | 3s ease-in-out infinite |

```less
  top: 0; left: 0; right: 0;

.nav-bar__inner {
  display: flex;
  align-items: center;

  padding: 0 16rpx;

  flex: 1;
  text-align: center;
  font-size: 34rpx;
  font-weight: 700;
  color: #fff;
  letter-spacing: 2rpx;
}
```

页面内容区需要 `padding-top: {{ navBarHeight + 10 }}px` 避让。

### 6.2 卡片

```less
.card {
  margin: 16~20rpx 24~28rpx;
  background: linear-gradient(180deg, #FFFAF5, #FFF3E0);
  border-radius: 24~28rpx;
  padding: 28rpx;
  box-shadow: @shadow-raised;  // 双阴影
  animation: fadeInUp 0.4s ease forwards;
  // 交错延迟: style="animation-delay: {{index * 60}}ms"
}
```

### 6.3 筛选标签（Filter Pills / Chips）

```less

  padding: 10~12rpx 24rpx;

  font-size: 24rpx;
  color: @color-text-sub;

  box-shadow: @shadow-raised;

    transform: scale(0.95);

  color: #fff;

  box-shadow: 0 4rpx 12rpx rgba(255, 152, 0, 0.25);

```

### 6.4 搜索输入框

```less

  align-items: center;
```

## 十、装饰技巧

### 10.1 浮动装饰圆

在页面头部 `::before` / `::after` 伪元素中放置半透明圆形，配合 `float` 动画增加层次感：

```less
.header::before {
  content: '';
  width: 120rpx; height: 120rpx;
  border-radius: 50%;
  background: rgba(255, 255, 255, 0.15);
  animation: float 6s ease-in-out infinite;
}
```

### 10.2 渐变分割线

板块标题左侧使用渐变色条：

```less
.section-title::before {
  content: '';
  width: 8rpx; height: 32rpx;
  border-radius: 4rpx;
  background: linear-gradient(180deg, #FF9800, #FFB74D);
}
```

### 10.3 交错入场动画

列表卡片通过 `animation-delay` 实现瀑布式入场：

```wxml
<view class="card" style="animation-delay: {{index * 60}}ms">
```

## 十一、禁止事项

1. **只用 .less 编写样式**，禁止直接编辑 `.wxss` 文件
2. **禁止使用 px 单位**，统一使用 `rpx`
3. **禁止修改品牌色** `#FF9800`
4. **禁止使用冷灰色阴影**，阴影必须带暖棕色调
5. **禁止引入外部 CDN 资源**，所有资源本地化
6. **禁止使用 eval()**，防止 XSS
7. **Vant 组件不能直接 flex:1**，需用 view 包裹
