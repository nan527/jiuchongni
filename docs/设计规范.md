# 就宠你 - 设计规范

## 一、设计目标

**温暖治愈风**：通过暖色调、圆润造型、柔和光影，营造温馨友好的宠物服务平台氛围。

---

## 二、色彩体系

### 2.1 品牌主色

| 颜色 | 色值 | 用途 |
|------|------|------|
| 品牌橙 | `#FF9800` | 主按钮、导航栏、选中状态、重要元素 |
| 浅橙 | `#FFB74D` | 渐变辅助色、悬浮状态 |
| 深橙 | `#F57C00` | 按下状态、强调文字 |

### 2.2 背景色

| 颜色 | 色值 | 用途 |
|------|------|------|

## 十一、自定义导航栏规范

### 11.1 配置要求

```json
{
  "navigationStyle": "custom"
}
```

### 11.2 结构要求

```wxml
<view class="nav-bar" style="padding-top:{{statusBarHeight}}px;">
  <view class="nav-bar__inner">
    <view class="nav-bar__back" bindtap="onGoBack">
      <van-icon name="arrow-left" size="40rpx" color="#fff" />
    </view>
    <text class="nav-bar__title">页面标题</text>
    <view class="nav-bar__right"></view>
  </view>
</view>
```

### 11.3 JS 计算

```javascript
onLoad() {
  const sysInfo = wx.getSystemInfoSync();
  const menuBtn = wx.getMenuButtonBoundingClientRect();
  const statusBarHeight = sysInfo.statusBarHeight || 20;
  const navBarHeight = menuBtn.top + menuBtn.height;
  this.setData({ statusBarHeight, navBarHeight });
}
```

## 十二、响应式规范

### 12.1 单位使用

- 使用 `rpx` 作为尺寸单位
- 1rpx = 0.5px（在 750px 设计稿下）

### 12.2 布局方式

- 使用 Flexbox 布局
- 避免使用 float
- 使用 `vw`/`vh` 处理全屏布局

---

## 十三、可访问性规范

### 13.1 对比度

- 主文字与背景对比度 ≥ 4.5:1
- 大文字与背景对比度 ≥ 3:1

### 13.2 触摸区域

- 最小触摸区域：44px × 44px
- 按钮间距：至少 8px

---

## 十四、禁止事项

1. **禁止使用外部 UI 库**：只使用 Vant Weapp
2. **禁止修改品牌色**：#FF9800 是固定品牌色
3. **禁止使用 px 单位**：统一使用 rpx
4. **禁止直接编辑 .wxss 文件**：必须编辑 .less 文件
5. **禁止引入外部 CDN 资源**：所有资源本地化
6. **禁止使用 eval()**：防止 XSS 攻击
