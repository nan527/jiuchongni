## 五、云函数 action 清单

云函数 `ai_handler` 通过 `action` 参数分发：

| action | 说明 |
|--------|------|
| `smart_match_parse` | AI 解析用户自然语言需求 |
| `health_risk_analysis` | AI 健康风险分析 |
| `get_openid` | 获取当前用户 openid |
| `find_user_by_openid` | 按 openid 查找用户 |
| `delete_agency` | 删除机构档案 |
| `get_file_urls` | 批量获取云文件临时 URL |
| `update_agency_audit` | 更新机构审核状态 |
| `reset_password` | 重置密码 |
| `bind_wechat` | 绑定微信 |
| `get_api_configs` / `save_api_config` | API 配置管理 |
| `check_quota` / `use_quota` | AI 配额管理 |
| `get_user_balance` / `recharge` / `deduct_balance` | 余额管理 |
| `get_balance_logs` | 余额变动记录 |
| `update_order_status` | 机构更新订单状态（含笼位校验） |
| `update_order_cage` | 机构更新笼位号 |
| `update_order_reply` | 机构回复评价 |
| `create_agency_order` | 机构从帖子创建订单 |
