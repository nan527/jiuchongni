# 就宠你 — 项目结构文档

## 一、项目概览

| 项目 | 说明 |
|------|------|
| 项目名称 | 就宠你（JCN）— 宠物智能服务平台 |
| 项目类型 | 微信小程序 |
| 前端框架 | 微信小程序原生（WXML / WXSS / JS） |

## 二、三大角色体系

### 1. 宠物主人（pet_owner）

**定位：** 智能寄养、健康管理、AI 创作

**入口页面：** `/pages/index/index`（Tab 页面）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 首页服务广场 | `pages/index` | 展示最新寄养/领养/机构服务信息 |
| 寄养中心 | `pages/foster-center` | 三 Tab：我的发布、我参与的、机构订单 |
| 发布寄养 | `pages/foster` | 选择宠物档案、填写寄养信息、上传图片 |
| 发布领养 | `pages/adopt` | 选择宠物档案、填写领养信息、上传图片 |
| 寄养详情 | `pages/foster-detail` | 查看/编辑/关闭/删除帖子，申请寄养/领养 |
| 服务详情 | `pages/service-detail` | 查看机构服务、选择宠物、笼位检查、下单 |
| 宠物档案 | `pages/pet` | 宠物 CRUD、25 种预设头像、自定义上传 |
| 订单中心 | `pages/orders` | 查看订单、确认完成、评价打分 |
| 个人中心 | `pages/my` | 个人信息、导航入口 |
| 个人资料 | `pages/profile` | 编辑头像、昵称、手机、邮箱、简介 |
| 社区论坛 | `pages/forum` | 浏览帖子、全部/我的 Tab、点赞 |
| 发帖 | `pages/post` | 标题、内容、图片、话题标签 |
| 帖子详情 | `pages/post-detail` | 查看帖子、点赞、评论 |

### 2. 寄养机构（agency）

**定位：** 订单处理、环境打卡、客户管理

**入口页面：** `/pages/agency/agency`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 机构首页 | `pages/agency` | 数据看板（订单数、服务数），导航入口 |
| 机构注册 | `pages/agency-register` | 完整注册表单：机构信息、资质上传、账号密码 |
| 机构编辑 | `pages/agency-edit` | 编辑机构资料、笼位数量、环境图片 |
| 订单管理 | `pages/agency-orders` | 四 Tab：待确认/进行中/待确认取回/已完成，笼位容量检查 |
| 服务管理 | `pages/agency-services` | 服务列表、按类别分组（寄养/美容/医疗/上门/附加） |
| 添加服务 | `pages/agency-services-add` | 25 种服务模板、价格校验、图片上传 |
| 收入统计 | `pages/agency-revenue` | 总览统计、月度柱状图、订单状态饼图、分类收入、每日订单 |
| 评价管理 | `pages/agency-reviews` | 评价列表、按服务/评分筛选、好评率、评分分布 |

### 3. 平台管理员（admin）

**定位：** 资质审核、系统监控、全局看板

**入口页面：** `/pages/admin/admin`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 管理后台 | `pages/admin` | 管理员首页，角色守卫，导航入口 |
| 机构审核 | `pages/admin/audit` | 待审核/已拒绝列表，查看详情，通过/拒绝操作 |

> 默认管理员账号：`admin` / `admin123`（首次启动自动创建）

## 三、角色路由与认证机制

```
启动 → app.js silentLogin()
         ↓
    authService.checkLogin()
         ↓
    ┌─ 本地缓存有效 → 直接跳转对应角色首页
    └─ 缓存过期/不存在 → 查询云数据库 users 集合
                            ↓
                    ┌─ 找到 → 刷新缓存，跳转
                    └─ 未找到 → 停在登录页
```

| 角色 | 登录方式 | 路由方式 | 特殊要求 |
|------|---------|---------|---------|
| 宠物主人 | 微信一键登录 / 账号密码 | `wx.switchTab` | 无 |
| 机构 | 账号密码 | `wx.redirectTo` | 必须 `auditStatus === 'approved'` |
| 管理员 | 账号密码 | `wx.redirectTo` | 无 |

## 五、云数据库集合

| 集合名称 | 使用者 | 用途 |
|---------|--------|------|
| `users` | authService, profile, admin/audit | 用户账号（所有角色） |
| `agency_profiles` | authService, agency-edit, agency-orders, service-detail | 机构商业档案 |
| `pets` | pet, foster, adopt, service-detail, health, match | 宠物档案 |
| `fosters` | index, foster-center, foster-detail | 寄养需求列表 |
| `adoptions` | index, foster-center, foster-detail, adopt | 领养列表 |
| `foster_applications` | foster-center, pet, foster-detail | 寄养/领养申请 |
| `user_orders` | orders, agency-orders, agency-revenue, agency-reviews, service-detail, foster-detail | 全部订单（个人 + 机构） |
| `agency_services` | index, agency-services, agency-services-add, service-detail | 机构服务列表 |
| `posts` | forum, post, post-detail | 社区论坛帖子 |
| `comments` | post-detail | 帖子评论 |
| `health_records` | health | 宠物健康数据 |
| `agencies` | match | 机构匹配数据（可能未创建） |
