# 就宠你 — 项目结构文档

## 一、项目概览

| 项目 | 说明 |
|------|------|
| 项目名称 | 就宠你（JCN）— 宠物智能服务平台 |
| 项目类型 | 微信小程序 |
| 前端框架 | 微信小程序原生（WXML / WXSS / JS） |
| UI 组件库 | Vant Weapp ^1.11.7 |
| 样式方案 | Less 预处理器 + WXSS |
| 后端服务 | 微信云开发（云函数 + 云数据库） |
| 存储 | 微信云存储 |
| 认证方式 | 微信登录 + 账号密码双模式 |
| 品牌色 | #FF9800（暖橙色） |

## 二、三大角色体系

### 1. 宠物主人（pet_owner）

**定位：** 智能寄养、健康管理、AI 创作

**入口页面：** `/pages/index/index`（Tab 页面）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 首页服务广场 | `pages/index` | 展示推荐机构、推荐服务 |
| 浏览机构 | `pages/browse-agencies` | 机构列表、搜索筛选 |
| 浏览服务 | `pages/browse-services` | 服务列表、分类筛选、价格区间筛选 |
| 机构详情 | `pages/agency-detail` | 机构信息、服务列表 |
| 服务详情 | `pages/service-detail` | 查看服务、选择宠物、笼位检查、下单 |
| 智能匹配 | `pages/smart-match` | AI 自然语言解析、硬性筛选、软性评分 |
| 宠物档案 | `packagePet/pages/pet` | 宠物 CRUD、25 种预设头像、自定义上传 |
| 宠物详情 | `pages/pet-detail` | 宠物详情、健康记录 |
| 健康管理 | `pages/health` | 健康记录、体重趋势、疫苗时间线、AI 风险预警 |
| 添加健康记录 | `pages/health-add` | 添加体重、疫苗、驱虫、体检记录 |
| 订单中心 | `pages/orders` | 查看订单、筛选、确认完成、评价打分 |
| 订单详情 | `pages/order-detail` | 订单详情、状态流转、修改/删除评价 |
| 支付页 | `pages/payment` | 待支付倒计时、取消订单 |
| 个人中心 | `pages/my` | 个人信息、导航入口、展示宠物预览 |
| 个人资料 | `pages/profile` | 编辑头像、昵称、手机、邮箱、简介 |

### 2. 寄养机构（agency）

**定位：** 订单处理、环境打卡、客户管理

**入口页面：** `/pages/agency/agency`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 机构首页 | `pages/agency` | 数据看板（订单数、服务数），导航入口 |
| 机构注册 | `pages/agency-register` | 完整注册表单：机构信息、资质上传、账号密码 |
| 机构编辑 | `pages/agency-edit` | 编辑机构资料、笼位数量、环境图片 |
| 浏览机构 | `pages/browse-agencies` | 机构列表（共用） |
| 机构详情 | `pages/agency-detail` | 机构信息（共用） |

| 服务管理 | `pages/agency-services` | 服务列表、按类别分组 |
| 添加服务 | `pages/agency-services-add` | 25 种服务模板、价格校验、图片上传 |
| 收入统计 | `pages/agency-revenue` | 总览统计、月度柱状图、订单状态饼图 |
| 评价管理 | `pages/agency-reviews` | 评价列表、按服务/评分筛选、好评率 |

### 3. 平台管理员（admin）

**定位：** 资质审核、系统监控、全局看板

**入口页面：** `/pages/admin/admin`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|

## 三、角色路由与认证机制

```
启动 → app.js silentLogin()
         ↓
    authService.checkLogin()
         ↓
    ┌─ 已主动登出（jcn_logged_out 标记）→ 返回 null
    ├─ 本地缓存有效 → 直接跳转对应角色首页
    └─ 缓存过期/不存在 → 查询云数据库 users 集合
                            ↓
                    ┌─ 找到 → 刷新缓存，跳转
                    └─ 未找到 → 停在登录页
```

| 角色 | 登录方式 | 路由方式 | 特殊要求 |
|------|---------|---------|---------|
| 宠物主人 | 微信一键登录 / 账号密码 | `wx.switchTab` | 无 |
| 机构 | 账号密码 | `wx.redirectTo` | 必须 `auditStatus === 'approved'` |
| 管理员 | 账号密码 | `wx.redirectTo` | 无 |

## 七、共享工具函数（utils/helpers.js）

| 函数 | 说明 | 使用页面 |
|------|------|---------|
| `CAT_TITLE_MAP` | 服务分类标题映射 | index, agency-detail, service-detail, browse-services |
| `formatDate(t)` | 格式化日期为 MM-DD | health, orders, agency-orders |

| `buildLeaveRemainText(leaveTimeMs)` | 构建离开剩余时间文本 | orders |
| `isLeaveExpired(leaveTimeMs)` | 判断是否已超过离开时间 | orders |
