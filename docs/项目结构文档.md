## 一、项目概览

| 项目 | 说明 |
|------|------|

| 项目类型 | 微信小程序 |
| 前端框架 | 微信小程序原生（WXML / WXSS / JS） |

## 二、三大角色体系

### 1. 宠物主人（pet_owner）

**定位：** 智能寄养、健康管理、AI 匹配

**入口页面：** `/pages/index/index`（Tab 页面）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 首页服务广场 | `pages/index` | 展示推荐机构、推荐服务、智能匹配入口 |
| 浏览机构 | `pages/browse-agencies` | 机构列表、搜索筛选 |
| 浏览服务 | `pages/browse-services` | 服务列表、分类筛选（4类：寄养/美容/医疗/上门）、价格区间筛选 |
| 机构详情 | `pages/agency-detail` | 机构信息、服务列表 |
| 服务详情 | `pages/service-detail` | 查看服务、选择宠物、笼位检查、下单 |
| 智能匹配 | `pages/smart-match` | AI 自然语言解析 + 同义词扩展 + 硬性筛选 + 软性评分（满分100） |
| 宠物档案 | `packagePet/pages/pet` | 宠物 CRUD、25 种预设头像、自定义上传 |
| 宠物详情 | `pages/pet-detail` | 宠物详情、健康记录 |
| 健康管理 | `pages/health` | 健康记录、体重趋势、疫苗时间线、AI 风险预警 |
| 添加健康记录 | `pages/health-add` | 添加体重、疫苗、驱虫、体检记录 |
| 订单中心 | `pages/orders` | 查看订单、状态筛选、确认完成、评价打分 |
| 订单详情 | `pages/order-detail` | 订单详情、状态流转、修改/删除评价 |
| 支付页 | `pages/payment` | 待支付倒计时、取消订单 |
| 个人中心 | `pages/my` | 个人信息、导航入口、展示宠物预览 |
| 个人资料 | `pages/profile` | 编辑头像、昵称、手机、邮箱、简介 |

### 2. 寄养机构（agency）

**定位：** 订单处理、笼位管理、客户管理

**入口页面：** `/pages/agency/agency`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 机构首页 | `pages/agency` | 数据看板（订单数、服务数），导航入口 |
| 机构注册 | `pages/agency-register` | 完整注册表单：机构信息、资质上传、账号密码 |
| 机构编辑 | `pages/agency-edit` | 编辑机构资料、笼位数量、环境图片 |
| 订单管理 | `pages/agency-orders` | 四 Tab：待接单/进行中/待确认/已完成。通过云函数操作订单（绕过安全规则） |
| 服务管理 | `pages/agency-services` | 服务列表、按类别分组（4类） |
| 添加服务 | `pages/agency-services-add` | 服务模板、价格校验、图片上传 |
| 收入统计 | `pages/agency-revenue` | 总览统计、月度柱状图、订单状态饼图 |
| 评价管理 | `pages/agency-reviews` | 评价列表、按服务/评分筛选、好评率、回复评价 |
| 宠物管理 | `pages/agency-pets` | 笼位网格、寄养中宠物管理、笼位分配/移动 |
| 机构帖子 | `pages/agency-posts` | 浏览寄养/领养帖子、从帖子接单 |

### 3. 平台管理员（admin）

**定位：** 资质审核、系统监控、全局看板

**入口页面：** `/pages/admin/admin`（非 Tab）

| 功能模块 | 页面路径 | 说明 |
|---------|---------|------|
| 管理后台 | `pages/admin` | 管理员首页，角色守卫，导航入口 |
| 机构审核 | `pages/admin/audit` | 待审核/已拒绝列表，查看详情 |
| 审核详情 | `pages/admin/audit-detail` | 单个机构审核详情 |
| 机构列表 | `pages/admin/agencies` | 全部机构管理 |
| 平台数据 | `pages/admin/dashboard` | Tab 切换：总览、审核状态、类型分布、收入统计 |
| API 配置 | `pages/admin/api-config` | AI 模型 API 密钥配置 |

> 默认管理员账号：`admin` / `admin123`（首次启动自动创建）

## 三、角色路由与认证机制

```
启动 → app.js silentLogin()
         ↓
    authService.checkLogin()
         ↓
    ┌─ 已主动登出（jcn_logged_out 标记）→ 返回 null
    ├─ 本地缓存有效 → 直接跳转对应角色首页
    └─ 缓存过期/不存在 → 查询云数据库 users 集合
                            ↓
                    ┌─ 找到 → 刷新缓存，跳转
                    └─ 未找到 → 停在登录页
```

| 角色 | 登录方式 | 路由方式 | 特殊要求 |
|------|---------|---------|---------|
| 宠物主人 | 微信一键登录 / 账号密码 | `wx.switchTab` | 无 |
| 机构 | 账号密码 | `wx.redirectTo` | 必须 `auditStatus === 'approved'` |
| 管理员 | 账号密码 | `wx.redirectTo` | 无 |

## 五、云数据库集合

| 集合名称 | 用途 | 主要操作方 |
|---------|------|-----------|
| `users` | 用户账号（所有角色） | authService, profile, admin |
| `agency_profiles` | 机构商业档案 | authService, agency-edit, agency-orders, admin |
| `pets` | 宠物档案 | pet, service-detail, health, smart-match |
| `user_orders` | 全部订单（机构服务订单） | orders, order-detail, agency-orders, service-detail |
| `agency_services` | 机构服务列表（4类） | agency-services, browse-services, service-detail |
| `health_records` | 宠物健康数据 | health, health-add |
| `health_risk_records` | AI 健康风险预警结果 | health |
| `posts` / `fosters` / `adoptions` | 寄养/领养帖子 | agency-posts |
| `api_configs` | AI 模型 API 配置 | admin/api-config |
| `user_balances` | 用户余额 | balance |
| `balance_logs` | 余额变动记录 | balance |

## 六、云函数 action 清单

云函数 `ai_handler` 是统一入口，通过 `action` 参数分发：

| action | 说明 | 调用方 |
|--------|------|--------|
| `smart_match_parse` | AI 解析用户自然语言需求 | smart-match |
| `health_risk_analysis` | AI 健康风险分析 | health |
| `get_openid` | 获取当前用户 openid | 登录流程 |
| `find_user_by_openid` | 按 openid 查找用户 | authService |
| `delete_agency` | 删除机构档案 | admin |
| `get_file_urls` | 批量获取云文件临时 URL | 多页面 |
| `update_agency_audit` | 更新机构审核状态 | admin |
| `reset_password` | 重置密码 | login |
| `bind_wechat` | 绑定微信 | login |
| `get_api_configs` | 获取 API 配置 | admin |
| `save_api_config` | 保存 API 配置 | admin |
| `check_quota` / `use_quota` | AI 配额管理 | health, smart-match |
| `get_user_balance` / `recharge` / `deduct_balance` | 余额管理 | balance |
| `get_balance_logs` | 余额变动记录 | balance |
| `update_order_status` | 机构更新订单状态 | agency-orders |
| `update_order_cage` | 机构更新笼位号 | agency-pets |
| `update_order_reply` | 机构回复评价 | agency-reviews |
| `create_agency_order` | 机构从帖子创建订单 | agency-posts |
