# 就宠你 — 智能匹配算法文档

> 最后更新：2026-06-14

---

## 一、算法概述

智能匹配采用 **两阶段架构**：

1. **AI 意图解析**：调用 MiMo（mimo-v2.5-pro）将用户自然语言转为结构化需求
2. **本地匹配评分**：硬性筛选（不通过直接排除）+ 软性评分（加权打分排序）

## 三、硬性筛选

硬性筛选不通过的服务直接排除，不进入评分阶段。

### 3.1 服务类型筛选

```js
// 用户指定 serviceCategory 时，只保留该类别的服务
if (parsed.serviceCategory) {
  filtered = filtered.filter(({ service }) =>
    service.category === parsed.serviceCategory
  );
}
```

### 3.2 地区匹配

```js
// 用户指定 location 时，只保留该城市的机构
if (parsed.location) {
  filtered = filtered.filter(({ agency }) =>
    _isLocationMatch(parsed.location, agency.region)
  );
}
```

**匹配逻辑**（`_isLocationMatch`）：

1. **直接匹配**：机构区域包含用户城市，或用户城市包含机构区域
2. **省份→城市匹配**：用户说省份（如"黑龙江"），机构城市在该省（如"哈尔滨"）
3. **城市→省份匹配**：用户说城市（如"太原"），机构省份名在该城市所属省（如"山西"）

### 3.3 预算筛选

```js
// 用户指定了预算上限时，排除价格超过上限的服务
if (parsed.budget && parsed.budget.max) {
  filtered = filtered.filter(({ service }) => {
    const price = Number(service.price) || 0;
    return price <= parsed.budget.max;
  });
}
```

## 四、软性评分

通过硬性筛选的服务进入评分阶段。**满分 85 分**。

### 4.1 评分公式

```js
_calcScore({ service, agency }, parsed, userLocation) {
  let score = 10;  // 基础分（通过硬性筛选）

  // 1. 关键词匹配 (+30)
  // 2. 偏好匹配 (+25)
  // 3. 环境展示度 (+15)
  // 4. 紧急度加成 (+5)

  return score;  // 范围: 10 ~ 85
}
```

### 4.2 维度详情

| 维度 | 权重 | 计分规则 | 搜索范围 |
|------|------|---------|---------|
| 基础分 | 10 | 通过硬性筛选即得 | - |
| 关键词匹配 | +30 | 每命中 1 个 +8，上限 30 | 服务名称、描述、机构介绍、服务范围、机构名称 |
| 偏好匹配 | +25 | 每命中 1 个 +10，上限 25 | 机构介绍、服务范围、笼位描述 |
| 环境展示度 | +15 | 有环境图片 +15，无图片 +3 | 机构 envImages 字段 |
| 紧急度加成 | +5 | urgency=urgent 且为寄养服务且有空笼位时 +5 | - |

### 4.3 关键词匹配详情

```js
// 搜索文本池（转小写）
const textPool = [
  service.name,        // 服务名称
  service.desc,        // 服务描述
  agency.orgIntro,     // 机构介绍
  agency.serviceScope, // 服务范围
  agency.orgName       // 机构名称
].join(' ').toLowerCase();

// 计算命中数
const keywordHits = (parsed.keywords || [])
  .filter(kw => textPool.includes(kw.toLowerCase()));

// 加分：每个 +8，上限 30
score += Math.min(keywordHits.length * 8, 30);
```

### 4.4 偏好匹配详情

```js
// 偏好搜索池（转小写）
const prefPool = [
  agency.orgIntro,     // 机构介绍
  agency.serviceScope, // 服务范围
  agency.cageDesc      // 笼位描述
].filter(Boolean).join(' ').toLowerCase();

// 计算命中数
const prefHits = (parsed.preferences || [])
  .filter(p => prefPool.includes(p.toLowerCase()));

// 加分：每个 +10，上限 25
score += Math.min(prefHits.length * 10, 25);
```

## 五、结果处理

### 5.1 排序与截断

```js
// 按分数降序排列，取前 10 条
const results = scored
  .sort((a, b) => b.matchScore - a.matchScore)
  .slice(0, 10);
```

### 5.2 百分比计算

```js
const MAX_SCORE = 85;
r.matchPercent = Math.min(Math.round(r.matchScore / MAX_SCORE * 100), 100);
```

示例：
- 60 分 → 71%
- 85 分 → 100%
- 10 分（仅基础分）→ 12%

### 5.3 匹配理由生成

```js
_generateReason({ service, agency, matchScore }, parsed) {
  const reasons = [];

  // 硬性筛选理由
  if (parsed.location && agency.region) {
    reasons.push('位于' + parsed.location);
  }
  if (parsed.budget && parsed.budget.max) {
    reasons.push('价格在预算范围内');
  }

  // 软性评分理由
  if (parsed.preferences && parsed.preferences.length > 0) {
    // 计算偏好命中
    const hits = parsed.preferences.filter(p => prefPool.includes(p.toLowerCase()));
    if (hits.length > 0) reasons.push('满足' + hits.join('、') + '等偏好');
  }

  if (reasons.length === 0) reasons.push('综合评分较高');
  return reasons.slice(0, 2).join('，');
}
```

最多显示 2 条理由，优先显示硬性筛选理由。

## 六、完整流程图

```
用户输入自然语言
        ↓
  AI 解析需求（MiMo）
        ↓
  提取: serviceCategory, location, budget, keywords, preferences, urgency
        ↓
  查询所有已审核机构 + 服务
        ↓
  构建 (agency, service) 对
        ↓
  ┌─ 硬性筛选 ─────────────────────────┐
  │ 服务类型匹配 → 地区匹配 → 预算匹配 │
  └────────────────────────────────────┘
        ↓
  ┌─ 软性评分（满分 85）────────────────┐
  │ 基础分 10                            │
  │ + 关键词匹配 (每命中+8, 上限30)     │
  │ + 偏好匹配 (每命中+10, 上限25)      │
  │ + 环境展示度 (有图+15, 无图+3)      │
  │ + 紧急度加成 (+5)                    │
  └────────────────────────────────────┘
        ↓
  按分数降序排列，取前 10 条
        ↓
  转换为百分比，生成匹配理由
        ↓
  展示匹配结果列表
```

## 八、已知限制

1. **省市映射不完整**：仅覆盖 31 省主要城市，未覆盖地级市和县级市
2. **无 GPS 距离计算**：`agency_profiles` 无经纬度字段，无法计算真实距离
3. **关键词匹配为子串匹配**：`String.includes()` 可能产生误匹配（如"猫粮"匹配"猫"）
4. **服务数量限制**：每次查询最多 100 条服务（`limit(100)`）
5. **评分权重固定**：无法根据用户行为动态调整权重
