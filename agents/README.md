# Agents 目录

本目录存放 AI 助手的配置和上下文信息。

## 使用说明

**每次执行任务前，AI 必须先阅读以下文档：**

1. `docs/设计规范.md` - UI/UX 设计规范和品牌标准
2. `docs/开发规范.md` - 代码编写规范和最佳实践
3. `docs/页面功能说明.md` - 所有页面的详细功能说明
4. `docs/项目结构文档.md` - 项目架构和技术栈
5. `docs/任务执行文档.md` - 当前任务状态和待办事项

## AI 助手角色

### 1. 前端开发助手
- 负责微信小程序页面开发
- 遵循 Less 预处理器规范（必须编辑 .less 文件）
- 使用 Vant Weapp 组件库

### 2. UI/UX 设计助手
- 确保界面符合"温暖治愈风"设计目标
- 遵循品牌色 #FF9800 暖橙色体系
- 保持跨页面一致性

### 3. 代码审查助手
- 检查代码质量和安全性
- 识别潜在的技术债务
- 确保遵循开发规范

## 重要提醒

- **样式文件**：项目使用 Less 预处理器，必须编辑 `.less` 文件，不能直接编辑 `.wxss` 文件
- **品牌色**：#FF9800（暖橙色），禁止随意更改
- **组件库**：使用 Vant Weapp，不要引入其他 UI 库
- **云开发**：使用微信云开发，不要使用外部服务器
